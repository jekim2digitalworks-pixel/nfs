## 1. 이 시스템의 원칙

### 1.1 통일은 크롬이 아니라 소재가 만든다

1차 시안은 레일·상단바·탭을 세 화면에 복사해두고 시스템이라 불렀다가 기각됐다 — *"세 개 다 똑같은 UI에 색만 다르다"*.

**화면마다 구조가 다르고, 공유하는 것은 소재·타입·모션이다.**

| 화면 | 구조 | 주 오브젝트 | 광원 |
|---|---|---|---|
| 리포트 | 스크롤 스택 | 세그먼트 **링** | 상단 · 차가운 인디고 |
| 하루 | 미터 + 시간 격자 | 선형 **캡슐 미터** | 중앙 · 따뜻한 앰버 (`지금`이 광원) |
| 집중 | 크롬 없음, 오브젝트 1개 | **다이얼** + 블룸 | 다이얼 뒤 · 카테고리 색 |

### 1.2 크롬은 무채색, 콘텐츠가 색을 갖는다

버튼·탭·칩은 흰색 계열 투명도로만 만든다. **색은 카테고리와 상태에만 준다.**
화면별 성격은 배경 블룸의 **색온도**로 낸다.

### 1.3 걸리지 않는 제약은 설명하지 않는다

경고·안내는 실제로 발생할 때만 등장한다 (N-010).

## 2. 색

### 2.1 기반 (다크 온리 · 확정 N-016)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#08080B` | 화면 바탕 (집중 화면만 `#050507`) |
| `--s1` | `rgba(255,255,255,.045)` | 표면 1단 (카드·칩) |
| `--s2` | `rgba(255,255,255,.075)` | 표면 2단 (선택된 세그먼트) |
| `--hair` | `rgba(255,255,255,.09)` | 테두리 |
| `--hair-2` | `rgba(255,255,255,.055)` | 구분선 |
| `--tx` | `#F6F6F8` | 본문 |
| `--tx2` | `rgba(246,246,248,.60)` | 보조 |
| `--tx3` | `rgba(246,246,248,.34)` | 캡션·비활성 |

> `#000` 을 쓰지 않는다. `#08080B`는 미세하게 따뜻해서 유리 레이어가 얹혔을 때 회색으로 죽지 않는다.

### 2.2 카테고리 (확정 N-017)

|---|---|---|
| `--dev` | `#7C8CFF` | 개발 |
| `--meet` | `#FF8066` | 회의 |
| `--study` | `#B08BFA` | 학습 |
| `--family` | `#3DDC97` | 가족 |
| `--health` | `#FFC24B` | 건강 |
| `--self` | `#4DD8E8` | 개인 |
| `--chore` | `#8E9AAE` | 잡무 |

7색이 **링에서 동시에** 구분돼야 해서 명도를 비슷하게 맞추고 채도를 낮췄다.

### 2.3 상태

| 토큰 | 값 | 용도 |
|---|---|---|
| `--now` | `#FFB020` | 지금 선 · 하루 화면 광원 |
| 증가 | `#3DDC97` (bg `rgba(61,220,151,.13)`) | 전기 대비 증가 알약 |

### 2.4 앰비언트 블룸

각 화면의 성격을 만드는 유일한 대형 색면. `filter: blur(26~46px)` 를 건 radial-gradient.

| 화면 | 위치 | 색 |
|---|---|---|
| 리포트 | 상단 20% | `rgba(124,140,255,.30)` + 보조 `rgba(176,139,250,.16)` |
| 하루 | 중앙 42% | `rgba(255,176,32,.20)` + 보조 `rgba(124,140,255,.15)` |
| 집중 | 다이얼 뒤 | 카테고리 색 34% |

## 3. 타이포그래피

### 3.1 서체

```css
--f: 'Instrument Sans', 'Noto Sans KR', -apple-system, system-ui, sans-serif;
```

- **Instrument Sans** — 라틴·숫자. 타이트한 그로테스크. 숫자가 이 앱의 주인공이라 figure 품질로 골랐다
- **Noto Sans KR** — 한글. 스택 순서상 한글만 자동으로 받는다
- 폰트 스택 하나로 혼용 스크립트를 해결한다. 역할별로 다른 패밀리를 섞지 않는다

### 3.2 스케일

| 역할 | 크기 | 굵기 | 자간 |
|---|---|---|---|
| 히어로 숫자 | 62px | 600 | `-.045em` |
| 예산 숫자 | 42px | 600 | `-.045em` |
| 타이머 | 76px | 500 | `-.055em` |
| 화면 제목 | 25px | 600 | `-.035em` |
| 링 중앙 | 30px | 600 | `-.035em` |
| 목록 값 | 15.5px | 600 | `-.02em` |
| 본문 | 14.5px | 400 | `-.012em` |
| 라벨 | 12.5px | 400~500 | `-.01em` |
| 캡션 | 11.5px | 400 | `-.005em` |
| 마이크로 | 9.5~10.5px | 500~600 | `-.01em` |

**규칙:** 크기가 커질수록 자간을 좁힌다. 큰 숫자에 기본 자간을 쓰면 흩어져 보인다.

### 3.3 숫자

모든 숫자에 `.num` 클래스.

```css
.num{ font-variant-numeric: tabular-nums; font-feature-settings:"tnum" 1; }
```

타이머·미터처럼 값이 바뀌는 자리에서 **글자 폭이 흔들리면 조악해 보인다.** 예외 없이 적용한다.

### 3.4 단위 표기

숫자와 단위의 크기·색을 분리한다.

```html
<h1 class="num">187<em>시간</em>30<em>분</em></h1>
```
`em` = 숫자의 약 0.42배, `--tx2`, `font-weight:500`.

## 4. 형태 · 간격

| 토큰 | 값 | 용도 |
|---|---|---|
| `--r-xl` | 30px | 큰 카드 (예산·목록·인사이트) |
| `--r-lg` | 22~24px | 카드 내부 행 |
| `--r-md` | 16~18px | 타임라인 블록·일정 |
| 알약 | `99px` | 버튼·칩·탭·미터 |

- 좌우 여백: 화면 가장자리 **22px**, 카드는 **14px** (카드가 더 넓게 나가 화면을 채운다)
- 카드 내부 패딩: 18~20px
- 터치 타겟 최소 **44×44px**

## 5. 소재 (유리)

```css
background: linear-gradient(165deg, rgba(255,255,255,.07), rgba(255,255,255,.02));
border: 1px solid var(--hair);
backdrop-filter: blur(26px);
```

- 다크에서 **그림자는 거의 보이지 않는다.** 깊이는 그림자가 아니라 **밝기 차와 블룸**으로 만든다
- 떠 있는 요소(탭)만 예외적으로 `0 14px 40px rgba(0,0,0,.55)`
- 카테고리 틴트 블록은 `color-mix(in srgb, var(--c) 36%, transparent)` 로 만든다 — 색을 따로 정의하지 않는다

## 6. 컴포넌트

| 컴포넌트 | 규격 |
|---|---|
| **떠 있는 탭** | 하단 26px, 알약, `blur(30px) saturate(180%)`. 활성 탭은 흰 배경 + 검은 글자. ⚠️ `left:50%` 사용 시 `width:max-content` 필수 |
| **세그먼트 컨트롤** | 높이 34px, 알약, 활성은 `--s2` + inset 하이라이트 |
| **칩** | 높이 30~36px, 알약, `--s1` + `--hair` |
| **링 차트** | `r=76`, `stroke-width=13`, `butt` 캡, 세그먼트 간 6px 갭. 중앙은 총계가 아니라 **답** |
| **캡슐 미터** | 높이 11px, 세그먼트 간 3px 갭, 각 세그먼트 알약. 내 블록만 발광 |
| **다이얼** | `r=105`, `stroke-width=7`, `round` 캡, 그라디언트 스트로크 + 호흡 헤일로 |
| **주 버튼** | 높이 56px, 흰 배경 / 검은 글자 |
| **보조 버튼** | 높이 56px, `rgba(255,255,255,.07)` + `--hair` |
| **빈 슬롯** | 1px 점선 `rgba(255,255,255,.14)` |
| **스켈레톤** | `rgba(255,255,255,.055)` + 1.55s sweep. **정상 요소와 같은 반지름·높이·여백**, 폭은 실제 글자 수만큼. 링은 sweep 대신 1.9s breathe |
| **인라인 에러** | `--r-lg`, 테두리 `--warn` 34%, 배경 `--warn` 10%. 우측에 36px 재시도 알약 (탭 타겟 44px) |
| **실패 카드** | 정상 카드의 **자리와 높이를 그대로** 차지. 1px 점선 테두리 + 중앙 정렬 + 재시도 |
| **제안 배너** | 무채색 유리. ⚠️ 미연동은 에러가 아니라 **경고색을 쓰지 않는다** |

## 7. 모션

```css
--ease: cubic-bezier(.32,.72,0,1);   /* iOS 계열 감속 */
```

| 동작 | 값 |
|---|---|
| 진입 (스태거) | `translateY(14~16px)` + fade, 0.62~0.7s, 40~50ms 간격 |
| 아크 그리기 | `stroke-dashoffset` 1.0~1.4s, 0.25s 지연 |
| 호흡 (헤일로·블룸) | 5.5~6s, `ease-in-out`, 무한 |
| 진행 중 표시 | 펄스 2.4s |
| 버튼 누름 | `scale(.975)` |

**`prefers-reduced-motion: reduce` 에서는 모든 애니메이션을 끈다.** 호흡·펄스 포함.

## 8. 접근성

| 항목 | 기준 |
|---|---|
| 본문 대비 | `--tx` on `--bg` = 약 18:1 ✅ |
| 보조 텍스트 | `--tx2` ≈ 8:1 ✅ / `--tx3` ≈ 4.2:1 — **캡션 전용**, 본문 금지 |
| 색 단독 전달 금지 | 카테고리는 색 + **이름**을 항상 함께 |
| 포커스 | `:focus-visible` 로 2px 아웃라인. 마우스 클릭에는 안 뜬다 |
| 차트 | `role="img"` + `aria-label`에 값을 문장으로 |
| 터치 타겟 | 최소 44×44px |

## 9. 반응형

**모바일 전용(N-009) · 다크 온리(N-016).** 기준 폭 **390px** (iPhone 15/16 논리 해상도).

| 폭 | 처리 |
|---|---|
| ~520px | 전체 화면. `100dvh` (주소창 때문에 `100vh` 금지) |
