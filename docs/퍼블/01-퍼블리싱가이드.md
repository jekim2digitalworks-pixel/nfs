## 2. CSS 규칙

### 2.1 선택자

- 클래스 기반. **ID 선택자로 스타일링하지 않는다** (JS 훅으로만 사용)
- 요소 선택자와 클래스 선택자를 섞지 않는다 — 특정도가 서로를 무효화한다

```css
/* ✗ 이런 게 사고를 낸다 */
.section { padding: 20px }
section  { padding: 0 }      /* 어디서 이겼는지 추적 불가 */

/* ✓ */
.section { padding: 20px }
.section--flush { padding: 0 }
```

- 화면 전용 스타일은 루트에 화면 클래스를 걸고 그 안에서만 쓴다

```html
<body class="screen-day">
```

### 2.2 값

| 항목 | 규칙 |
|---|---|
| 색 | **반드시 토큰.** 하드코딩된 hex 금지 |
| 간격 | 4의 배수 (예외: 타임라인 `--hr:46px`) |
| 반경 | `--r-xl` / `--r-lg` / `--r-md` / `99px` |
| 카테고리 틴트 | `color-mix(in srgb, var(--c) 36%, transparent)` — 색을 새로 정의하지 않는다 |
| 뷰포트 높이 | **`100dvh`.** `100vh`는 모바일 주소창 때문에 잘린다 |

### 2.3 반드시 지킬 것

```css
/* 하단 탭 — left:50% 는 shrink-to-fit 폭을 절반으로 가둔다. 실제로 라벨이 세로로 깨졌다 */
.tabs{ left:50%; transform:translateX(-50%); width:max-content; }

/* 홈 인디케이터 영역 */
.tabs{ bottom: calc(26px + env(safe-area-inset-bottom)); }

/* 모션 감소 존중 — 호흡·펄스 포함 전부 */
@media (prefers-reduced-motion: reduce){
  *,*::before,*::after{ animation:none !important; transition:none !important }
}
```

## 3. 마크업 규칙

| 항목 | 규칙 |
|---|---|
| 시맨틱 | `header` / `main` / `section` / `nav` 사용. `div` 남용 금지 |
| 버튼 vs 링크 | 동작은 `<button>`, 이동은 `<a>`. **`<div onclick>` 금지** |
| 차트 | `role="img"` + `aria-label`에 값을 문장으로 |
| 숫자 | 모든 숫자에 `.num` (tabular-nums) |
| 라이브 영역 | 타이머는 `aria-live="off"` (매초 읽으면 소음). 상태 변경 시에만 `aria-live="polite"` 로 알림 |
| 포커스 | `:focus-visible`만 스타일. 마우스 클릭에 링이 뜨지 않게 |
| 터치 타겟 | 최소 44×44px |

### 3.1 XSS

사용자 입력이 들어가는 자리는 **블록 제목**과 **캘린더 일정 제목** 두 곳이다.

```jsp
<%-- JSP: 반드시 c:out --%>
<c:out value="${block.title}"/>
```
```js
// JS: textContent 사용. innerHTML 금지
el.textContent = block.title;
```

## 4. JS 규칙

### 4.1 Ajax 레이어 (`api.js`)

모든 통신은 이 레이어를 통한다. `$.ajax`를 화면 코드에서 직접 부르지 않는다.

```js
// 서버 응답 규약: { success, data } | { success, error:{ code, message } }
NFS.api.post('/api/blocks', payload)
  .done(function (data) { ... })
  .fail(function (error) {
    // error.message 는 사용자에게 그대로 보여줄 수 있는 한국어다.
    // 프론트에서 코드별 문구를 다시 만들지 않는다.
    NFS.toast(error.message);
  });
```

에러 코드별 **추가 동작**만 화면에서 분기한다.
예: `BUDGET_EXCEEDED` → `error.detail.occupiedBy`로 점유 내역 시트를 연다.

### 4.2 타이머 (`timer.js`) ⭐

**이 프로젝트에서 가장 많이 틀리는 부분이다.**

```
원칙
1. 클라이언트 타이머는 '표시 전용'이다. 정산은 서버가 한다.
2. 경과 시간을 setInterval 로 누적하지 않는다.
   → 탭이 백그라운드로 가면 브라우저가 타이머를 조인다. 값이 조용히 뒤처진다.
3. 서버가 준 기준 시각과 로컬 시각의 차이(offset)를 저장하고,
   매 틱마다 (Date.now() + offset) 으로 '지금'을 다시 계산한다.
4. visibilitychange 로 화면이 돌아오면 즉시 서버와 재동기화한다.
```

```js
// 개념 — 단계가 보이게 쓴다 (CLAUDE.md §3)
var serverOffsetMillis = 0;

function syncWithServer(response) {
    var serverTime = new Date(response.serverTime).getTime();
    var localTime = Date.now();
    serverOffsetMillis = serverTime - localTime;
}

function currentServerTime() {
    return Date.now() + serverOffsetMillis;
}

document.addEventListener('visibilitychange', function () {
    if (!document.hidden) {
        NFS.api.get('/api/blocks/current').done(syncWithServer);
    }
});
```

> `document.hidden` 상태에서 잰 값은 거짓이다. 참조 프로젝트 `cal_bak`이 한 세션에서 세 번 밟은 함정이고,
> **타이머 앱인 NFS는 훨씬 자주 밟는다.**

### 4.3 차트 (`chart.js`)

라이브러리를 쓰지 않는다. 필요한 건 세 가지뿐이고 전부 인라인 SVG/CSS로 만든다.

| 차트 | 방법 |
|---|---|
| 링 | SVG `circle` + `stroke-dasharray` / `stroke-dashoffset` 누적 |
| 캡슐 미터 | flex + `border-radius:99px` 세그먼트 |
| 타임라인 | 절대 배치. `top = (분 − 시작분) × (--hr / 60)` |

**타임라인 좌표는 서버가 준 분 값으로 계산한다.** 시안 작업 중 실제로
`10:00–11:30`(90분)을 150분으로 계산해 블록이 2.5시간짜리로 그려진 사고가 있었다.
헬퍼 하나로 고정한다.

```js
function minutesToPixels(minutes) {
    return minutes * (HOUR_HEIGHT_PX / 60);
}
```

## 5. JSP 규칙

| 항목 | 규칙 |
|---|---|
| 스크립틀릿 `<% %>` | **금지.** JSTL + EL만 |

| 초기 데이터 | 모델로 내려 첫 렌더에 반영. 첫 화면을 Ajax로 다시 부르지 않는다 |

| 캐시 | 정적 리소스는 쿼리스트링 버전 (`?v=${buildVersion}`) |

- [ ] 4가지 상태 구현 — 로딩(스켈레톤) · 정상 · 비어 있음 · 에러

- [ ] `prefers-reduced-motion`에서 애니메이션이 멈춘다
- [ ] 사용자 입력이 들어가는 자리가 전부 이스케이프됐다
- [ ] 숫자에 `.num`이 붙어 타이머가 흔들리지 않는다
- [ ] 실제 브라우저에서 렌더 확인 (스크린샷 첨부)
- [ ] 하드코딩된 색이 없다 (`grep -n '#[0-9a-fA-F]\{6\}' screen-*.css` 가 비어야 한다)
