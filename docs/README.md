## 이 프로젝트가 반복해서 밟게 될 것

| 함정 | 어디에 |
|---|---|
| ⭐ 실행 환경이 UTC라 배치가 9시간(주간은 요일까지) 어긋난다 | `개발/01`§6 · `테스트/01`§6 |
| JS `Date`에 날짜/시각 타입 구분이 없어 하루가 밀린다 | `개발/01`§6.1 |
| 서버리스에서 Prisma 커넥션이 고갈된다 | `개발/01`§7 |
| 서버 시크릿이 클라이언트 번들로 샌다 | `개발/01`§2.2 · §9 |
| 백그라운드 탭에서 잰 타이머 값은 거짓이다 | `퍼블/01`§4.2 · `테스트/01`§7.1 |
| 같은 블록이 두 번 정산된다 | `개발/02`§1.1 · `테스트/01`§3 |
| 우리가 쓴 캘린더 일정을 다시 읽어 이중 집계한다 | `기획/03`§4.1 |
| 예산 계산기가 두 벌이면 두 화면 숫자가 어긋난다 | `개발/02`§4 |
