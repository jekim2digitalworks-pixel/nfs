### 0.2 내비게이션

하단 **떠 있는 알약 탭** 3개: `리포트` · `하루` · `집중`.

- 진행 중인 블록이 **있으면** `집중` 탭 → S-04 (해당 블록)
- 진행 중인 블록이 **없으면** `집중` 탭 → S-05 (블록 생성 시트)
- **S-04는 탭 바를 숨긴다.** 몰입 화면이므로 크롬을 없앤다. 나가는 길은 좌상단 닫기뿐

### 0.3 공통 문구 규칙

| 원칙 | 예 |
|---|---|
| 시스템 용어 금지 | `동기화 실패` ✗ → `캘린더를 불러오지 못했어요` ✓ |
| 버튼은 일어날 일을 그대로 | `확인` ✗ → `블록 만들기` ✓ |
| 같은 동작은 같은 이름 | `완료` 버튼 → 완료 토스트 `완료했습니다` |
| 에러는 사과하지 않고 다음 행동을 준다 | `죄송합니다…` ✗ → `다시 불러오기` 버튼 ✓ |
| 내부 용어 노출 금지 | 실측/신고 ✗ → **집중 시간 / 일정 시간** ✓ |

### 0.4 공통 상태

모든 데이터 화면은 4가지 상태를 갖는다. **하나라도 빠지면 미완성이다.**

| 상태 | 처리 |
|---|---|
| 로딩 | 스켈레톤 (스피너 금지 — 레이아웃이 튄다) |
| 정상 | — |
| 비어 있음 | 다음 행동을 제안하는 문구 + 버튼 |
| 에러 | 무엇이 안 됐는지 + 재시도 버튼. 화면 전체를 덮지 않는다 |

## S-02 · 리포트

### 구성

| 영역 | 내용 | 데이터 |
|---|---|---|
| 기간 칩 | `2026년 8월 ⌄` — 탭하면 기간 선택 | — |
| 히어로 | 기간 총 시간 + 전기 대비 증감 | `GET /api/statistics/summary` |
| 세그먼트 | `전체` / `집중` / `일정` | 클라이언트 필터 |
| 링 | 태그별 분포. 중앙에 **가장 많이 쓴 곳** | `GET /api/statistics/by-tag` |
| 목록 | 태그별 행 (집중·일정 분리, 막대, 증감) | 위와 동일 |
| 인사이트 카드 | 계획과 실행의 격차 1건 | 서버 계산 |
| 월별 추이 | 12개월 막대 | `GET /api/statistics/monthly` |

### 기간 전환

`일 · 주 · 월 · 년` 4단계. 기본값은 **월**.
- **주**를 볼 때는 마감 상태 배지를 함께 표시 (`마감됨` / `집계 중` / `캘린더 미반영`)

### 인사이트 카드 규칙

- 표시 조건: 한 태그의 `일정 시간 ≥ 집중 시간 × 2` 이고 `일정 시간 ≥ 10시간`
- 조건에 맞는 태그가 없으면 **카드를 숨긴다.** 억지로 만들지 않는다
- 문구: `캘린더에서 가장 큰 자리를 차지한 건 {태그} {N}이었지만, 타이머가 실제로 돈 시간은 {M}입니다.`

### 상태별 화면

| 상태 | 화면 |
|---|---|
| 비어 있음 (기록 0) | `아직 기록이 없어요` + `첫 블록 만들기` 버튼 → S-05 |
| 캘린더 미연동 | 링·목록은 집중 시간만. 하단에 `구글 캘린더를 연결하면 일정 시간도 볼 수 있어요` 배너 |
| 해당 주 동기화 실패 | 주간 리포트 상단에 `이 주는 캘린더가 반영되지 않았습니다` |

## S-03 · 하루

### 구성

| 영역 | 내용 |
|---|---|
| 헤더 | `오늘` + 날짜 · 우측 캘린더 다시 불러오기 |
| 예산 카드 | 남은 시간(대) · 자정까지 남은 시간 · 캡슐 미터 · 범례 · 겹침 안내 |
| 타임라인 | 시간 격자 위에 캘린더 일정(뒤) + 블록(앞) + 지금 선 |

### 타임라인 규칙

| 항목 | 규칙 |
|---|---|
| 표시 범위 | 기본 `현재 −3시간 ~ +6시간`. 위아래 스크롤로 하루 전체 |
| 1시간 높이 | 46px |
| 캘린더 일정 | 전체 폭, 낮은 대비, 라벨 **우측 정렬**, 우측에 카테고리 색 바 |
| NFS 블록 | 좌측 69% 폭, 카테고리 틴트 유리, 캘린더 **위에 얹힘** |
| 겹침 배지 | **차감당하는 쪽(캘린더 일정)** 에 붙인다 — `1시간 겹침 · 차감` |
| 진행 중 블록 | 테두리 강조 + 펄스 점 + 하단 진행 바 |
| 지금 선 | 앰버 하이라이트 + 좌측 게터에 시각 알약 |
| 빈 자리 | 점선 슬롯 `＋ 블록 추가` (30분 이상 빈 구간에만) |

### 인터랙션

| 동작 | 결과 |
|---|---|
| 빈 슬롯 탭 | S-05 (시작 시각 프리필) |
| 블록 탭 | 진행 중 → S-04 / 완료 → 상세 시트 |
| 캘린더 일정 탭 | 액션 시트 → `통계에서 빼기` · `이 캘린더 전체 빼기` |
| 예산 미터 탭 | 오늘 점유 내역 목록 |

### 상태별 화면

| 상태 | 화면 |
|---|---|
| 블록·일정 모두 없음 | 타임라인 격자만 + 중앙 `지금부터 3시간, 무엇에 쓸까요?` + 버튼 |
| 캘린더 미연동 | 미터에 캘린더 세그먼트 없음. 범례에 `캘린더 연결` 링크 |
| 예산 초과 시도 | 시트 상단에 `오늘 남은 4시간을 넘습니다` + 점유 내역 + 정리 안내 (2.4) |
| 동기화 실패 | 헤더 아이콘 옆 점 + 탭하면 `캘린더를 불러오지 못했어요 · 다시 시도` |

## S-04 · 집중

### 구성

크롬 없음. 오브젝트 하나.

| 영역 | 내용 |
|---|---|
| 상단 | `오늘 남은 시간 N` (좌) · 닫기 ⌄ (우) |
| 태그 칩 | 카테고리명 + 색 점 |
| 제목 | 블록 제목 |
| 메타 | `14:00 – 15:00 · 60분 블록` |
| 다이얼 | 남은 시간(대) + 진행 아크 + 호흡하는 헤일로 |
| 사이클 | 뽀모도로 진행 (`1 / 2`) |
| 컨트롤 | `일시 정지` · `완료` |
| 하단 | 완료 후 처리 안내 + 캘린더 남기기 체크 |

### 상태별 표시

| 블록 상태 | 다이얼 | 컨트롤 |
|---|---|---|
| RUNNING (집중) | 카테고리 색 아크 · 헤일로 호흡 | `일시 정지` · `완료` |
| RUNNING (휴식) | 중립색 아크 · `휴식 중` 라벨 | `건너뛰기` · `완료` |
| PAUSED | 아크 정지 · 채도 하락 · `일시 정지됨` | `이어서 하기` · `완료` |
| 계획 시간 초과 | 아크 100% · 숫자가 `+03:12` 로 전환 | `완료` 강조 |

### 완료 처리

1. `완료` 탭 → 즉시 정산 (조기 완료면 `EARLY_FINISHED`)
2. 완료 시트: `개발에 51분 기록했습니다` + 오늘 누적 + `계속 이어서` / `오늘로 돌아가기`
3. 캘린더 남기기가 켜져 있으면 백그라운드로 전송 (실패해도 사용자 흐름을 막지 않는다 · Phase 2)

### 이탈 처리

- 앱을 나가거나 화면을 닫아도 **타이머는 서버에서 계속 흐른다.** 클라 타이머는 표시 전용
- 재진입 시 서버 시간으로 재동기화
- 자정을 넘기면 배치가 `AUTO_SETTLED`로 정산 (`03-서비스정책.md` 1.2)

## S-05 · 블록 생성 시트 (⬜ D-04)

### 입력

| 필드 | 규칙 |
|---|---|
| 카테고리 | **필수.** 7종 칩. 최근 사용 순 정렬 |
| 제목 | 선택. 비우면 태그명 |
| 시작 시각 | 30분 격자. 기본값 = 다음 격자 |
| 길이 | 30 / 60 / 90 / 120분 칩 |

### 검증 순서

1. 카테고리 미선택 → `카테고리를 골라주세요`
2. 길이가 30의 배수 아님 → (UI가 칩이라 발생 불가. 서버는 검증)
3. **예산 초과** → `오늘 남은 4시간을 넘습니다` + 점유 내역 + `통계에서 뺄 일정 고르기`
4. 통과 → 생성 후 S-04로 이동 (즉시 시작) 또는 S-03 유지 (나중에 시작)

### 미리보기

시트 상단에 실시간 갱신: `이 블록을 만들면 오늘 남은 시간 12시간 30분`
