## Q-010 · 평생 화면(S-06)의 기준 나이

D-03 시안 작업에 필요하다.

| 안 | 내용 | 장단 |
|---|---|---|
| **A (권장)** | **생년만 입력** 받고 기대수명 상수(한국 남녀 평균)로 계산 | 숫자가 내 것이 된다. 입력 1회 / 죽음을 상기시키는 UX라 거부감 가능 |
| B | 입력 없이 **50년 고정** (438,000시간) | 마찰 0 / 누구에게나 같은 숫자라 남의 이야기처럼 읽힘 |
| C | A를 기본, 건너뛰면 B로 폴백 | 절충 |

**막는 작업:** D-03
**현재 가정:** C (건너뛸 수 있는 선택 입력). 이 가정으로 시안을 진행해도 되는지 확인 필요
