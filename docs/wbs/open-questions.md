## ⛔ Q-009 · 로컬 개발 환경 설치 (사용자 작업)

N-012에 따라 **JDK 17과 Gradle 8이 필요**하다. 현재 로컬은 JDK 11 + Gradle 6.8.3이다.
설치는 시스템 변경이라 **사용자가 직접 해야 한다.**

| 필요 | 현재 | 확인 명령 |
|---|---|---|
| JDK 17+ | Temurin 11.0.29 | `java -version` |
| Gradle 8+ | 6.8.3 | `gradle -v` |
| MySQL 8 | 미확인 | `mysql --version` |

권장 설치 (Windows · winget)
```powershell
winget install EclipseAdoptium.Temurin.17.JDK
winget install Gradle.Gradle
winget install Oracle.MySQL
```
> Gradle Wrapper를 쓸 것이므로 **Gradle 전역 설치는 선택**이다. 다만 최초 `gradle wrapper` 생성에는 필요하다.
> JDK 17은 필수. 설치 후 `JAVA_HOME`을 17로 바꾸고 새 셸에서 `java -version`을 확인한다.

**막는 작업:** O-01 → Phase 1 전체
**필요한 답:** 설치 완료 여부 (또는 이미 설치돼 있다면 경로)
